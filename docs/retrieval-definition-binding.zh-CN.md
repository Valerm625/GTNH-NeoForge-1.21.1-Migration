# 从真实定义绑定检索物品

`LegacyRetrievalDefinitionBinding` 把完整源归档中的一个quest解析为已有纯规划器的检索声明，使用调用方提供的真实物品注册表和不可变 `FrozenStack` 谓词。它不接收可修改库存、不执行提交，也不把声明可绑定当作整项任务已迁移。

## 来源与语义

输入来自 `LegacyQuestDefinitionArchive`，结果携带整个归档摘要、定义/身份映射绑定、原quest与设置文件的原始字节、每项要求的旧ID、metadata、目标ID、数量和匹配开关。绑定失败时仍返回原件及具体路径上的诊断，不返回可执行的部分quest。

固定BQ 3.8.89源码的 `TaskRetrieval.readFromNBT` 会覆盖构造器默认值；缺失开关读作false，不能把默认true的ignoreNBT和partialMatch直接带入。任务顺序保留真实index，由规划器按index升序执行。数量单独保存在引擎Requirement，不借用现代ItemStack的一组上限。非全局任务保留globalShare，不据此改变检测。

普通旧ID/metadata必须存在于归档的明确映射表，并且目标存在于传入注册表中。不存在、空目标或非法ID均拒绝，没有空气、同名搜索或占位物回退。矿辞是完整集合要求；旧metadata通配符也可能跨多个现代ID，在集合映射完成前明确拒绝，不能映射成其中一种。

无NBT要求在 `ignoreNBT=false` 时使用严格组件比较，并沿用已验证的可损耗物品耐久归一化以及空自定义NBT等价规则。`partialMatch=true`不会让空要求接受额外名称或NBT，因为旧版CompareNBTTag先判断空与非空。非空要求NBT尚无组件映射时整体拒绝；显式 `ignoreNBT=true` 则按原算法忽略标签，仍完整保留原始要求。原始5760项检索物品要求中，127项非空NBT要求设置了ignoreNBT=true，576项要求仍需比较非空NBT。

检索层的OR、自动消耗、组检测和多要求消耗已完成16种组合模型对照，见[标志组合说明](retrieval-mode-parity.zh-CN.md)。未知任务工厂、未知检索字段、重复index，以及quest级非AND逻辑、重复、全局、同时完成和编辑模式，仍拒绝整份声明。奖励、前置条件、任务完成和其他完整定义字段保留在原件中，由后续对应服务处理；此绑定器不假装已经实现这些行为。

## 真实定义与实际物品验证

当前通过4112项断言、42次固定源码读取对照。测试直接读取3814个真实任务，并在原版注册表中得到39个完整检索检测声明。固定源 `readFromNBT` 的方法体原样提取执行，与已绑定任务的开关、要求列表和数量逐项比较；旧NBT/列表由现代NBT适配，物品重建部分保留原始compound，不声称运行了旧版注册表。

明确覆盖：

- 0:0要求8个泥土，7个不能完成，分槽达到8个完成且不消耗。
- 0:8的64圆石及原始globalShare设置保持。
- 0:27要求4个木炭，即旧 `minecraft:coal` 的metadata=1；普通煤不能替代。跨槽扣除4个，保留额外物品和现代副手，完成状态重放不重复扣物。
- 0:474要求256圆石，跨四组扣除，额外第五组保留。
- 0:2的logWood保持未解析缺口；0:1914的多要求消耗已按64绿宝石与8本书绑定并验证实际库存扣物。
- 合成定义检查省略开关、非空/空NBT、命名物品、磨损工具、稀疏/反向任务index、未知工厂、错误元数据、未注册目标和整份拒绝。

`LegacyQuestNativeLifecycle.retrievalDefinition(server, id)` 已连接挂载且通过pin检查的定义与服务器注册表。调用仍需在服务器线程上、加载准备成功之后；它只是声明查询，不创建世界账本，也不授权玩家操作。原生入场字节码审计检查此调用顺序。

## 边界与下一步

运行 `python work/migration/test_legacy_retrieval_definition_binding.py`，或使用完整重建入口。新生产类必须与最终兼容JAR逐字节一致。原版ItemStack与Inventory对象真实执行，但Inventory的玩家引用为空；授权/参与者是夹具，没有启动玩家、世界或完整模组注册过程。225次已映射目标缺失诊断来自仅含原版物品的验证注册表，不能解释为完整NeoForge模组注册已经失败或成功。

39个可绑定检测声明不等于39个可玩的完整任务；现有依赖闭合导出仍为2/3814。后续需要来源正确的前置/队伍授权、世界首次绑定与进度导入、持久化提交入口、完成/奖励状态机和完整UI，还须补全全部未支持任务模式、物品映射、模组功能与资源效果。真实游戏、客户端视觉和其他模组回调行为仍未验证。
