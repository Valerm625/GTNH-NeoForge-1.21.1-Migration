## 运行与恢复

这不是一键可重现发行包。工具目前依赖原工作区中已准备的精确上游源码、解析证据、下载缓存和安装运行时；全新 clone 仅有源码，不具备所有前置输入。不要直接执行所有历史脚本。请先读 `RESUME.md`。

Python 工具在 Python 3.14 / Pillow 12.3.0、Node.js 24.19 和 JDK 21 环境下检查。核心重建入口是 `python -u work/migration/rebuild_current_phase.py`，**仅在前置本地工作区恢复后**运行。
